A quieter indicator, a built-in tutorial, and fixes.

## What's new

- **A new corner indicator.** The logo in the top-left corner is gone. A small badge in the **top-right** corner, in a terminal font on black or white to match your theme, now shows where Inkling is:
  - `i_rdy` (orange) while you type your request,
  - `i_thnk` (blue) while Inkling thinks and types,
  - `i_fin` (green) for a moment when the answer is in,
  - `i_err` (red) if something goes wrong.
- **Select-to-ask and Try again show it too**, with `i_thnk` while they work and `i_fin` when they're done.
- **A tutorial.** One chapter per feature, from getting a key to using a command-line AI instead. Open it any time from the tray icon's menu (**Help → Tutorial**), from **Settings → About**, or from the welcome window.
- **Getting a free NVIDIA key is spelled out.** The welcome window and the README now list the three steps, and the link goes straight to the API keys page.
- **Better answers in Excel.** Inkling now asks for a spreadsheet formula there.
- The project is now called **Inkling for Windows** on GitHub. Old links redirect.

## Fixes

- Shortcuts with a number key (say Ctrl+Alt+5) didn't work: the 5 was read as a mouse button.
- With Settings open, changing the model or answer length from the tray, or skipping an update, could be undone by the next change made in Settings.
- Messages such as "Nothing selected" now show as a notification, since the corner badge has no room for them.
- The tray and Settings now use the same names for the answer lengths.

## For developers

**Indicator** (`Ui/StatusOverlay.cs`)
- `BadgeIndicator` replaces the corner logo: a layered window (`UpdateLayeredWindow`, per-pixel alpha) at the top-right of the target window's monitor work area, 8 px in, scaled by `DeviceDpi`. Text is Cascadia Mono Bold (Consolas if missing), 12 px at 100%, with a 4 px corner radius; black or white from `Theme`, through the new `StatusOverlay.Dark`.
- States and colours (`InklingArt`): Ready `i_rdy` in `Accent` #FF7D00, the underscore blinking every 0.53 s; Thinking `i_thnk` in `Thinking` #4D9BFF, blinking every 0.25 s; Done `i_fin` in `Done` #2DBE6C for 1.2 s; Error `i_err` in `Error` #FF5A5F for 2 s. The badge is sized for the widest text (`BadgeIndicator.Widest`), so it never changes size.
- `CaptureController` shows the thinking badge for every request (typed, selected, retry and after a risky-command confirm) and calls the new `StatusOverlay.ShowDone` once the answer is typed.
- In badge mode, every message except "Cancelled (...)" and "Not typed" is raised as a tray balloon.

**Tutorial and welcome** (`Ui/Wpf/`)
- New `TutorialWindow` (WPF, code only): chapters are plain records (paragraphs, numbered steps, copyable commands, notes), shown with a chapter list on the left. `ISettingsHost.ShowTutorial` opens it; `TrayApp` keeps one instance.
- `AppInfo.NvidiaKeysUrl` is the API keys page, used by the welcome window, Settings and the tutorial.

**Fixes**
- `Hotkey.Parse` checked `Enum.TryParse<Keys>` before single digits, and "5" parses as key code 5 (`XButton1`). Digits are now handled first, and all-digit names are refused.
- `SettingsWindow.Set` and `HotkeyChanged` start from a fresh clone of the app's config instead of the window's own copy, so changes made elsewhere aren't written back. The tray's model and length items call `SettingsWindow.Reload`.
- New `Contexts` rule for `EXCEL`; `AppConfig.Load` adds default rules whose process isn't in a saved config yet.
- An unknown or incomplete command-line option prints the options and exits with code 2 instead of starting the app.
- The repository moved to `AtharvGogia/Inkling-for-Windows`; the update check and links use the new name.

**Tests**
- New `Inkling.Tests` (xUnit, 69 tests): risky-command rules, snippets, answer cleaning, shortcut parsing (this found the digit bug), the prompt, per-app hints, update tag parsing, the badge's text and colour for each state, and that every benchmark grader is a valid regex. Run with `dotnet test Inkling.Tests`.
- The keyboard hook and typing into other apps aren't covered by these tests.

**Benchmark and docs**
- `bench/questions.json`: "remove all unused images" is now "remove all unused docker images". The old wording never said Docker, and two models answered with a `find … -delete`.
- README: the new indicator states, the free key steps, the tutorial, a "Test it" section, the two logo options, and corrected claims (which models were tested, how the keyboard hook works, Windows 10 untested).
- Screenshots now show the whole window with its frame, and the GIFs show a Windows taskbar with Inkling's tray icon.
