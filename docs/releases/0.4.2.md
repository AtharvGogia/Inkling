The first public release of Inkling: press a shortcut anywhere in Windows, type what you want, press Enter, and the answer is typed in its place.

## What's in it

- **Ask anywhere** with Ctrl+Alt+Space. Answers fit the app you're in: a bash or PowerShell command in a terminal, a formula in Excel, code in your editor, plain words elsewhere.
- **Ask about selected text** with Ctrl+Alt+Enter: the selection is the request and the answer replaces it.
- **Try again** with Ctrl+Alt+R for a different answer.
- **Risky commands** (rm -rf, DROP TABLE, git reset --hard…) are shown first and only typed after you press Enter.
- **Snippets**: your own instant replies, no model involved. {date}, {time} and {clipboard} are filled in.
- **Fast answers** from NVIDIA's free API: about 0.4 s with Nemotron 3.5 Bolt. Laguna XS 2.1 is the other choice.
- **Settings** for shortcuts (recorded by pressing them), answer length, theme, typing speed, apps where Inkling stays off, and more.
- **Updates** are checked once a day and installed with one click.

## Getting started

Run `Inkling-Setup-0.4.2.exe`. It installs for your user only, without an admin prompt. On first start, paste a free API key from [build.nvidia.com](https://build.nvidia.com/); Inkling checks that it works and keeps it in Windows Credential Manager.

The installer isn't code-signed, so SmartScreen may warn you the first time: choose **More info → Run anyway**.

## For developers

**Capture** (`CaptureController.cs`, `Input/`)
- A `WH_KEYBOARD_LL` / `WH_MOUSE_LL` hook on the UI thread drives an Idle → Capturing → Thinking → (Confirming) → Typing state machine. The typed request is rebuilt from the keystrokes with `ToUnicodeEx` on the foreground thread's layout; arrows, Tab, clicks, a window switch or a Ctrl/Alt/Win shortcut cancel, since the text on screen can no longer be tracked.
- Injected input carries the marker `0x1A1A0001` in `dwExtraInfo` and is ignored by the hook. After a shortcut with Alt or Win, an unassigned key (VK `0xE8`) is sent so the app doesn't open its menu or Start.
- `InputSender.TypeTextAsync` sends characters on the target's layout as real virtual keys (`VkKeyScanEx`, Shift held across the key) and anything else (emoji, AltGr, dead keys) as `KEYEVENTF_UNICODE` packets, paced per key (5 ms, 30 ms for `SlowApps`) with `timeBeginPeriod(1)`. WinUI Notepad garbles unpaced input ("Jupiter" → "rrrrrrr").
- Select-to-ask copies the selection with an atomic Ctrl+C `SendInput` batch, waits on `GetClipboardSequenceNumber`, and puts every clipboard format back. VS Code's whole-line copy is spotted through its `isFromEmptySelection` flag. Terminals are refused.
- Retry keeps the last answer until any other key, click or window switch, and sends the rejected answers with the request.

**Answers** (`Ai/ChatApiBackend.cs`, `Ai/Prompt.cs`, `ForegroundContext.cs`)
- One shared `HttpClient` (HTTP/2, pooled connection). `Warm()` sends `GET /models` when the shortcut is pressed so the TLS handshake overlaps typing, skipped if the connection was used in the last 90 s. Requests are streamed (`stream: true`); with one-line answers, reading stops at the first complete line.
- The message holds the app's file description, process name, window title (optional) and a per-app hint (`Contexts`: bash for Windows Terminal, PowerShell, cmd, code for VS Code…), plus five few-shot examples sent as earlier turns.
- `max_tokens` is 768 / 1024 / 1536 by answer length, so models that reason first still get to the answer; `reasoning_content` deltas are counted, not shown, and `<think>` blocks are stripped.
- A sliding 60 s window keeps under the key's limit (`NimRequestsPerMinute`, 38) and fails fast instead of waiting on a 429.
- The models were chosen with `--bench`: 42 graded questions in 14 domains through this same path (`bench/questions.json`, results in `bench/results`).
- The Claude Code and Antigravity CLIs remain as optional backends (`Ai/StreamCliBackend.cs`): kept warm in stream-json mode, one request per process, in a kill-on-close job object. For Claude the answer is taken from the `assistant` event, skipping the CLI's post-turn summary call (about 3 s).

**Safety and privacy**
- `RiskGuard.cs`: 16 regex rules with a 50 ms timeout each; a match puts the answer in a red confirm bar until Enter. `--risk-test` checks 21 risky and 18 safe samples.
- `Secrets.cs`: the key is a generic credential `Inkling:nim` via `CredWriteW` / `CredReadW`, with `NVIDIA_API_KEY` as fallback. It's never written to `config.json` or the log.
- `DisabledApps`: the hook passes the shortcuts through when the foreground process is on the list.
- The log holds timings and errors only. `Diagnostics.cs` keeps per-request timings (context, connection, first token, answer, parsing, erase, typing) without any text.

**Snippets and updates**
- `Snippets.cs`: an exact, case- and space-insensitive match on the request skips the model; `{date}`, `{time}`, `{datetime}` and `{clipboard}` are filled in. Snippets are never retried or risk-checked.
- `Updates.cs`: `GET /repos/AtharvGogia/Inkling/releases/latest` once a day (drafts and pre-releases never show up there). The installer asset (`Inkling-Setup-*.exe`) is only downloaded from `github.com` over HTTPS and run with `/SILENT /SUPPRESSMSGBOXES`; the installer closes Inkling and starts the new version.

**Windows** (`Ui/Wpf/`)
- WPF with `ThemeMode` (Fluent) inside the WinForms tray app: a `System.Windows.Application` is created without `Run`, and windows are shown with `ElementHost.EnableModelessKeyboardInterop`.
- `Theme.cs` recolours Fluent: its accent brushes hold the resolved Windows accent colours, so every brush or colour matching `SystemColors.AccentColor*` is overridden on the window with the matching step of #FF7D00.
- `HotkeyBox` records shortcuts, refuses ones Windows or every app relies on, and checks with `RegisterHotKey` whether another program owns one (Inkling itself uses the hook, not `RegisterHotKey`).
- `config.json` saves go through a temporary file; an unreadable file is kept aside as `config.invalid-<time>.json`.

**Logo and media**
- `Ui/InklingArt.cs` draws the logo from Georgia italic outlines (bold italic below 28 px): `--write-icon` writes the .ico, `--write-logo-svg` the README SVGs with the letters as paths.
- `--render-ui` and `--render-media` render the Settings tabs and the README GIFs off-screen (mock scenes drawn frame by frame, encoded with FFmpeg); nothing on the real screen is recorded.

**Build**
- .NET 10, self-contained single-file `win-x64` with compression; Inno Setup per-user installer (`PrivilegesRequired=lowest`) that closes a running Inkling before installing and starts it again after a silent upgrade.
- Checked for this release: the risky-command test (21/21 caught, 18/18 left alone), the update check against the public repo, and the windows rendered off-screen from the published single-file exe. Typed requests, select-to-ask and retry were tested live in Notepad on earlier builds, not on this one.
